### 9-Box Breakdown

[INSTRUCTION: Once a pitch is bet on, break the solution into 9 distinct phases or scope areas for tracking during Building. These aren't sequential sprints — they're pieces of the solution that can each be marked done independently, so progress reads as "which boxes are done" rather than a single percentage.]

[EXAMPLE: For a "recommended next action in market alerts" pitch — 1. Data model for recommendation rules, 2. Rule engine for surfacing a recommendation, 3. UI component in the alert view, 4. Empty/fallback state, 5. Analytics instrumentation, 6. Edge case: no recommendation available, 7. Edge case: multiple qualifying recommendations, 8. Copy and content review, 9. Rollout/flagging plan.]

[INSTRUCTION: If a box can't be marked done by the end of the cycle, that's signal, not failure — see [Building](../rituals/building.md) for what happens when the cycle ends before every box is done.]
